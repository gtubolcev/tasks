# Перенос доработок инструментов из форков OGAM

Шесть патчей для [off-grid-ai/OGAM](https://github.com/off-grid-ai/OGAM) с исправлениями
и улучшениями из форков `fl4p/off-grid-ai-mobile`, `VadimBir/OGAM-Fixed` и
`longregen/off-grid-mobile-ai`. Всё адаптировано к текущему коду оригинала.

Основа: `8cb28cd34` (`chore(beta): 0.0.124-beta.2`, 11.11.2026).

## Как применить

```bash
git clone https://github.com/off-grid-ai/OGAM && cd OGAM
git checkout -b tool-fixes 8cb28cd34   # или текущий main, если он ушёл недалеко
git am /путь/к/ogam-tool-fixes/patches/*.patch
```

Каждый патч самостоятелен. Если нужен не весь набор, берите отдельные файлы.

## Патчи

| # | Что | Откуда | Файлы |
|---|-----|--------|-------|
| 1 | **Параллельные вызовы инструментов при стриминге собираются по `index`.** Сейчас аргументы двух вызовов (GLM, Kimi K2) склеиваются в один JSON, и ход падает. Дополнительно учтены серверы, которые для каждого вызова шлют index 0 и новый id. | fl4p `a781199d8` + доработка | `providers/openAICompatibleStream.ts`, `…Types.ts` |
| 2 | **SSRF в `read_url`.** Хост теперь берётся через `URL`, а не регулярным выражением: `http://user@10.0.0.1/` больше не проходит. Добавлены IPv6 (`::1`, `fc00::/7`, `fe80::/10`, `::ffff:…`), CGNAT `100.64/10`, хосты облачных метаданных, `.local`/`.internal` и однословные имена. **Новое:** проверяется и конечный адрес после редиректа. | fl4p `216c73494`, longregen `f417b1a8c` + своё | `tools/privateUrl.ts` (новый), `tools/handlers.ts` |
| 3 | **Разметка вызовов DeepSeek (DSML, `<｜DSML｜invoke …>`)** теперь разбирается как обычный `<invoke>`, не показывается в чате при стриминге, а `<parameter … string="true">` принимается. Если в последнем ходе после лимита модель выдала одну разметку, показываются собранные результаты инструментов, а не «(No response)». | fl4p `3c58b8f77`, `3f39fc319` (адаптировано) | `generationToolLoop.ts`, `utils/messageContent.ts` |
| 4 | **Фраза «у тебя нет инструментов»**, когда у модели нет ни встроенных, ни MCP-инструментов. Иначе модель уверяет, что «запустила код». | fl4p `68a62a632`, `56944410f` | `tools/registry.ts`, `ChatScreen/useChatGenerationActions.ts` |
| 5 | **Служебные проходы llama (выбор инструментов на 64 токена, сжатие контекста) идут без «размышлений».** Сейчас reasoning-модель тратит весь бюджет на `<think>`, и выбор инструментов возвращает пустой ответ. | VadimBir `de880edd7` | `services/llm.ts` |
| 6 | **Подсказка для моделей без встроенного вызова инструментов** теперь содержит точный синтаксис `<tool_call>{…}</tool_call>`, аргументы с типами и пример для каждого инструмента. Раньше было только «- имя: описание». | VadimBir `64a5008ba` (часть) | `tools/registry.ts` |

К каждому патчу добавлены тесты рядом с существующими.

## Что проверено, а что нет

- ✅ Серия чисто применяется через `git am` к `8cb28cd34`.
- ✅ `tsc --noEmit` не даёт новых ошибок. Сравнивал со сборкой без патчей: у оригинала без закрытого
  репозитория `off-grid-ai/shared` (`@offgrid/*`) есть ~1200 своих ошибок, но новых нет ни одной.
- ✅ Новый модуль SSRF-проверки и регулярные выражения DSML отдельно прогнаны в Node на всех
  случаях из тестов.
- ❌ **Jest не запускался.** Тесты зависят от закрытых пакетов `@offgrid/*`, а выполнять код
  скачанного репозитория среда не разрешила. Перед слиянием прогоните у себя:
  ```bash
  npx jest __tests__/unit/services/providers/openAICompatibleStream.test.ts \
    __tests__/unit/services/tools __tests__/unit/services/generationToolLoop.branches.test.ts \
    __tests__/unit/utils/messageContent.test.ts __tests__/unit/services/llm.test.ts
  ```
  и затем весь набор: патч 4 добавляет строку в системный промпт чатов без инструментов, и тест,
  сверяющий промпт целиком, может это заметить. Я таких тестов не нашёл, но гарантии без прогона нет.

## Что сознательно не перенесено

- **VadimBir `294f5f229` (`callsWithinToolBudget` «возвращает boolean»).** В оригинале бага нет:
  настоящая функция из `@offgrid/models` обрезает массив, и это закреплено тестом оригинала
  (`counts every parallel call against one total response budget`). У VadimBir падение вызывала
  собственная заглушка закрытого пакета.
- **VadimBir `a53c7c76d` (`generate_image` вытесняет текстовую модель).** В оригинале нет
  инструмента `generate_image`.
- **Крупные функции fl4p** (`run_python` на Pyodide, файловые инструменты, память, поиск
  Serper/Brave, общий переключатель онлайн-инструментов). Это тысячи строк, новые нативные
  зависимости (`react-native-webview`, static-server) и код на основе оригинала от 27.06. Их нужно
  переносить отдельными задачами, а не патчем.
- **`tool_choice: 'none'` в последнем ходе (fl4p `4065beead`).** С июля этот ход в оригинале
  переписан, а его симптом, разметка в ответе, закрывает патч 3.

## Остаточные риски

- SSRF: защиты от DNS rebinding нет. Проверка после редиректа срабатывает, когда запрос уже
  выполнен, хотя тело ответа модели не отдаётся. Полное решение — свой resolver или запрет
  редиректов на нативной стороне.
